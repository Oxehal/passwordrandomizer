# 🔐 Quick PassGen

Простой и легковесный генератор криптографически стойких паролей и токенов на Python.

## 🚀 Особенности
- Использует стандартный модуль `secrets` (подходит для секретных ключей, API-токенов и паролей).
- Без внешних зависимостей — работает «из коробки».
- Настраиваемая длина и поддержка спецсимволов.

## 📦 Быстрый старт

Запуск скрипта:
```bash
python main.py
🛠 Пример использования в коде
Python
from main import generate_password

# Пароль по умолчанию (длина 16, со спецсимволами)
pwd = generate_password()

# Токен из 32 символов только из букв и цифр
token = generate_password(length=32, use_special=False)
